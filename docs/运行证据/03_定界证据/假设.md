# 假设

每条假设都指向一段，并挂着支撑它的证据。

### H1 → interface

引用证据：EV-054、EV-055、EV-050

算法在将视觉检测结果转换为法兰指令时，使用了 T_tcp_to_flange（工具变换的逆）而非 T_flange_to_tcp（工具变换本身），导致法兰指令在工具轴方向上偏低 2×tool_length = 70mm。这是 transform chain 中工具复合方向的代码缺陷。修复方式：在算法代码中找到计算法兰位姿的位置，将 T_flange_to_tcp 的应用从 '减去' 改为 '加上'（或从逆矩阵改为正向矩阵）。依据：check_transform_chain 中 tool0_to_tcp 的 error_vs_inverse_twice 残差为 0，且两个工件的 70mm Z 轴偏差精确等于 2×0.035m 工具长度。

### H1 → interface

引用证据：EV-054、EV-055、EV-056

pick_demo/pipeline.py 的 flange_command_for_tcp() 函数对 inverse(tool0_to_tcp) 累积调用了 3 次，正确做法只需 1 次。多余的 2 次导致法兰指令 Z 偏高 2×0.035=0.07m，使 TCP 停在工件上方约 70mm。这是代码缺陷，非标定漂移或配置写反。修复后复跑 exit_code=0，法兰 Z 从 0.253 修正为 0.183，差值恰好等于 2×35mm。
